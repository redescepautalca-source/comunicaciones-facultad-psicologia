# Sistema de Newsletters y Mailing — Facultad de Psicología / CEPA

Repositorio de gestión, planificación y versionado de comunicaciones digitales de la Facultad de Psicología y el Centro de Psicología Aplicada (CEPA) de la Universidad de Talca.

---

## ¿Qué contiene este repositorio?

| Carpeta | Contenido |
|---------|-----------|
| `01-planificacion/` | Calendarios editoriales, campañas, fechas de envío |
| `02-plantillas/` | Arquitecturas editoriales: newsletters (CEPA, Facultad) y mailing de promoción (Educación Continua) |
| `03-ediciones/` | Contenido concreto de cada mes (borradores, aprobados, enviados) |
| `04-recursos/` | Imágenes, logos, iconos, tipografías institucionales |
| `docs/` | Versiones HTML para visualización web (GitHub Pages) |

---

## Tipos de comunicación

| Tipo | Audiencia | Frecuencia | Objetivo |
|------|-----------|------------|----------|
| **Newsletter CEPA** | Comunidad interna + externa cercana | Bimensual | Informar, vincular, comunidad |
| **Newsletter Facultad** | Estudiantes, académicos, funcionarios | Bimensual | Informar, fortalecer comunidad |
| **Mailing Educación Continua** | Público externo (profesionales, empresas) | Por campaña | Vender cursos, generar inscripciones |

---

## Flujo de trabajo

1. **Planificar** → `01-planificacion/`
2. **Definir estructura** → `02-plantillas/[tipo]/estructura.md`
3. **Redactar contenido** → `03-ediciones/[año]/[mes]/`
4. **Revisar y aprobar** → Pull request o comentarios en el archivo
5. **Diseñar / Maquetar** → `docs/` (versión HTML)
6. **Enviar** → Outlook (copiar HTML o pegar contenido)
7. **Archivar** → Mover a `enviados/` y registrar métricas
